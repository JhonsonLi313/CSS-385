# CSS-385

So the interaction model I have is a button and door and I've also added coins. The objective of the button and door is to give the players an objective to work towards. The players know there is something in their way blocking them from leaving and a big red button is suspiciously sitting there.
With the coins I haven't thought of a specific use for it other than some sort of collectible that I can keep behind a breakable wall which would be another interaction model I can add in.

I want to eventually have it so a button in let's say level 1, when pressed will affect a door in level 2. This would promote the player to explore their surroundings when I start adding forked paths and give them multiple options. With the coin it is just a collectible for score keeping.
I could add some sort of shop in the game but I just don't know what I would sell in it at the moment and how I would even implement it.
